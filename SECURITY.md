# Security Policy

## Supported Versions

| Version | Supported |
| --- | --- |
| 1.0.x | :white_check_mark: |
| < 1.0 | :x: |

## Reporting Security Vulnerabilities

Please **do not report security-critical vulnerabilities through public GitHub Issues**.

Confidential reports should be sent by email to:

**bylicki@mail.de**

Please include:

- affected version or component
- short technical description
- steps to reproduce
- possible impact

Do not include passwords, private keys, or other sensitive data.

## Responsible Disclosure

Please allow sufficient time for investigation and remediation before publicly disclosing a vulnerability.

Testing must only be performed on systems and data for which you have explicit authorization.

## Scope

Security reports may include issues related to encryption, key management, signatures, QSEC files, the SQLite Key Vault, and security-relevant dependencies.

## Notice

BylickiLabs Post Quantum Security is not formally certified. Users are responsible for determining whether the software meets their individual security and compliance requirements.
